Avenvault Maven Repository

Welcome! This is the central public dependency repository for Avenvault projects. You can browse and search all available libraries in the sidebar on the left.

How to use in your project:

<repositories>
    <repository>
        <id>avenvault-discord</id>
        <url>https://maven.plugins.avenvault.com/discord/</url>
    <repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>com.avenvault.discord</groupId>
        <artifactId>AeroDesk-API</artifactId>
        <version>1.0.0</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
